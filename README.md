# primeiro-pr-demo

Pequena coleção de funções utilitárias de matemática em Python, criada como
projeto de exemplo.

## Funções

- `is_prime(n)`: retorna `True` se `n` for um número primo.
- `fibonacci(n)`: retorna os primeiros `n` números da sequência de Fibonacci.

## Uso

```python
from mathutils import is_prime, fibonacci

is_prime(7)        # True
fibonacci(5)        # [0, 1, 1, 2, 3]
```
